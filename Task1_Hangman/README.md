# 🎮 Hangman Game

A simple text-based Hangman game developed in Python as part of the CodeAlpha Python Programming Internship.

## 🎯 Objective

The player has to guess a randomly selected word by entering one letter at a time.

## ✨ Features

* 5 predefined words
* Random word selection
* Letter-by-letter guessing
* Maximum 6 incorrect guesses
* Prevents duplicate guesses
* Input validation
* Win/loss detection

## 🧠 Concepts Used

* `random`
* Lists
* Strings
* Loops
* Conditional statements
* User input

## ▶️ How to Run

```bash
python hangman.py
```

## 🎮 Example

```text
Word: _ _ _ _ _ _

Enter a letter: p
Correct guess!

Word: p _ _ _ _ _

Enter a letter: y
Correct guess!

...

Congratulations!
You guessed the word: python
```
