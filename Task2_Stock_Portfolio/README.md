# 📈 Stock Portfolio Tracker

A simple Python application that calculates the total investment value of a stock portfolio.

## 🎯 Objective

The program allows the user to select stocks, enter quantities, and calculate the total investment based on predefined stock prices.

## ✨ Features

* Predefined stock prices
* Stock symbol validation
* User-defined quantities
* Individual investment calculation
* Total investment calculation
* Portfolio summary
* Saves results to a text file
* Input validation

## 🧠 Concepts Used

* Dictionaries
* Lists
* Loops
* Conditional statements
* Arithmetic operations
* File handling
* Exception handling

## ▶️ How to Run

```bash
python stock_portfolio.py
```

## 📊 Example

```text
Stock     Price       Quantity    Investment
------------------------------------------------------------
AAPL      $180        5           $900
TSLA      $250        3           $750
NVDA      $130        10          $1300
------------------------------------------------------------
Total Investment: $2950
```

## 📄 Output File

The program generates:

```text
portfolio.txt
```

containing the portfolio report and total investment.
