## 📌 Projects

### 1. 🎮 Hangman Game

A simple console-based Hangman game where the player guesses a randomly selected word one letter at a time.

#### Features

* 5 predefined words
* Random word selection
* Letter-by-letter guessing
* Maximum 6 incorrect guesses
* Input validation
* Win and game-over conditions
* Console-based interface

#### Concepts Used

* `random`
* Lists
* Strings
* `while` loop
* `if-else`
* User input

#### Run the Project

```bash
cd Task1_Hangman
python hangman.py
```

---

### 2. 📈 Stock Portfolio Tracker

A console-based stock portfolio tracker that calculates the total investment value based on predefined stock prices and user-entered quantities.

#### Features

* Hardcoded stock price dictionary
* User can enter stock symbols
* User can enter quantities
* Calculates individual investment values
* Calculates total portfolio investment
* Displays portfolio summary
* Saves the result to `portfolio.txt`
* Handles invalid input

#### Concepts Used

* Dictionaries
* Lists
* User input/output
* Arithmetic operations
* File handling
* Exception handling

#### Run the Project

```bash
cd Task2_Stock_Portfolio
python stock_portfolio.py
```
